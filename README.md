# CineBryan

## Descripción
CineBryan es un sistema web para registrar ventas de boletos
y controlar operaciones básicas de una taquilla de cine.

## Objetivo
Facilitar el registro de ventas, el cálculo de ingresos
y el control de cambios de asiento.

## Funcionalidades principales
- Inicio de sesión.
- Registro de ventas de boletos.
- Cálculo de ingresos por venta.
- Cambio de asiento con recargo según el horario.
- Gráfica de ingresos registrados.
- Captura de foto del operador.

## Tecnologías
- HTML: estructura de la página.
- CSS: diseño y apariencia visual.
- JavaScript: funciones y cálculos.
